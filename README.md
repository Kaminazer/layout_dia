# Dia landing page

## Опис проекту

Dia — це сучасна лендинг-сторінка для креативної агенції, що спеціалізується на дизайні та розробці. Проект включає адаптивний дизайн, інтерактивні елементи та сучасні анімації для кращого користувацького досвіду.

## Технології

- HTML5
- SCSS
- JavaScript
- BEM методологія
- Parcel
- Swiper.js
- Stylelint
- Prettier

## Встановлення та запуск

```bash
# Клонування репозиторію
git clone https://github.com/kaminazer/layout_dia.git

# Перехід у директорію проекту
cd layout_dia

# Встановлення залежностей
npm install

# Запуск проекту в режимі розробки
npm start

# Збірка проекту
npm run build
```

### Додаткові команди

- `npm run lint` - перевірка коду
- `npm run format` - форматування коду
- `npm test` - запуск тестів
